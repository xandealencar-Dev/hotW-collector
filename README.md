# 🚗 Minha Coleção - PortableGarage

> Sua coleção de Hot Wheels organizada em um só lugar.

O **Minha Coleção - PortableGarage** é uma aplicação web criada para ajudar colecionadores de Hot Wheels a organizar, consultar e acompanhar seus carrinhos de forma simples e prática.

A ideia surgiu de uma situação bem comum para quem coleciona: conforme a coleção cresce, fica cada vez mais difícil lembrar quais modelos já possui, quais ainda procura e quais gostaria de comprar.

O PortableGarage transforma essa coleção física em uma **garagem digital**, acessível pelo computador ou celular.

## 📸 Sobre o projeto

O PortableGarage permite que o colecionador tenha em um único lugar informações sobre os modelos que possui e os que ainda deseja encontrar.

Entre as principais funcionalidades estão:

- 🔐 Autenticação de usuários
- 🚗 Cadastro de carrinhos na coleção
- 📷 Scanner de código de barras
- 🔎 Pesquisa no catálogo
- 📖 Visualização de detalhes dos modelos
- ❤️ Sistema de favoritos
- ⭐ Lista de desejos
- 📱 Interface responsiva
- 🌙 Interface com tema escuro
- 📲 Suporte a PWA
- ☁️ Integração com Supabase

# ✨ Funcionalidades

## 📷 Scanner de código de barras

Uma das principais funcionalidades do PortableGarage é o scanner integrado ao sistema.

O usuário pode utilizar a câmera do celular para ler o código de barras da embalagem de um Hot Wheels.

O processo funciona da seguinte maneira:

```text
📷 Escanear código
       ↓
🔢 Identificar código
       ↓
🔎 Consultar catálogo
       ↓
🚗 Modelo encontrado
       ↓
📖 Ver detalhes
       ↓
➕ Adicionar à coleção
